# Безопасность

## Ключи API

- Ключи хранятся только на устройстве, в `SharedPreferences` ("secrets").
- Сами значения шифруются AES-256-GCM ключом AndroidKeyStore (alias `anyailive_master`).
- Расшифрованный ключ живёт только в памяти процесса.
- Ключи уходят только на сервер, который пользователь сам указал в настройках модели (base URL).

## Сеть и приватность

- Серверов приложения нет, телеметрии нет, аккаунтов нет.
- Чат и HTTP-аудио отправляются на настроенные API, Live — на realtime-эндпоинт
  (при пустом адресе используется адрес протокола по умолчанию). Системные службы
  распознавания и синтеза могут отдельно обращаться к своим облачным сервисам.
- Live-движки скрывают ключ из текстов ошибок. Полная проверка всех ошибок и системных
  логов на отсутствие секретов пока не проведена; не публикуйте сырые логи без проверки.
- HTTP разрешён намеренно: приложение поддерживает любой HTTP-адрес, который
  пользователь сам указал в настройках модели, — не только localhost. Такой трафик
  идёт открытым текстом: API-ключ (у Gemini он передаётся в URL запроса), текст
  сообщений и аудио реплик видны любому, кто видит канал. Используйте HTTPS/WSS где
  это возможно, а HTTP-адрес — только в доверенной сети.

## Резервное копирование

- Резервное копирование приватных данных отключено: `android:allowBackup="false"`
  плюс явные исключения для облачного бэкапа и переноса на другое устройство
  (`app/res/xml/backup_rules.xml` для API 24-30, `app/res/xml/data_extraction_rules.xml`
  для API 31+). Исключены все приватные домены: database, sharedpref, files, external, root.
- Без этого в бэкап попадали бы переписка (SQLite `anyailive.db`), `SharedPreferences`
  "secrets" и записи аудио реплик из `filesDir/audio`.
- Ключ шифрования живёт в AndroidKeyStore и в бэкап не попадает, поэтому ключевые
  блобы, восстановленные из чужого бэкапа, всё равно не расшифровываются.

## Аудио

- Аудио микрофона при живом разговоре уходит владельцу realtime-эндпоинта (OpenAI/Gemini/ваш).
- Запись реплик включается вручную (галочка «Сохранять аудио реплик») и хранится локально.
