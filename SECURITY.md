# Безопасность

## Ключи API

- Ключи хранятся только на устройстве, в `SharedPreferences` ("secrets").
- Сами значения шифруются AES-256-GCM ключом AndroidKeyStore (alias `voicebridge_master`).
- Расшифрованный ключ живёт только в памяти процесса.
- Ключи уходят только на сервер, который пользователь сам указал в настройках модели (base URL).

## Сеть и приватность

- Серверов приложения нет, телеметрии нет, аккаунтов нет.
- Приложение ходит только на: базовый URL моделей, realtime-эндпоинты, которые пользователь
  сам добавил в каталог.
- Логи сохраняются только локально и не содержат ключей: из текстов ошибок ключи вырезаются.

## Аудио

- Аудио микрофона при живом разговоре уходит владельцу realtime-эндпоинта (OpenAI/Gemini/ваш).
- Запись реплик включается вручную (галочка «Сохранять аудио реплик») и хранится локально.

## Сообщить о проблеме

Открывайте issue в репозитории; ключи и тулзы в issue не выкладывать.
